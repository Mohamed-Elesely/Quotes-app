# Quotes App

Android app written in Kotlin that shows a random quote from a web API and lets you save favorite quotes on the device.

## Features
- Random quote on the home screen
- Save quotes to favorites
- Favorites list stored locally with Room

## Tech stack
- Kotlin, Android SDK
- MVVM (ViewModel, LiveData)
- Retrofit with Gson for the API call
- Room for local storage
- Navigation Component with fragments
- Glide for images

## Run it
1. Clone the repository.
2. Open it in Android Studio and let Gradle sync.
3. Run the `app` configuration on an emulator or a device.
